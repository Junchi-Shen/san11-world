# 地图与城市

## 改城市数量

改 `project.json` 的 `cities`（含光荣的 42 座），然后：

```bat
python san11kit.py world
```

城市是按「重要程度」排好队的，城市数改小就去掉排在后面的小城，改大就从候选表里往后补。
城市数不同，存档互不通用，要开新游戏。

## 改势力、军团数量

光荣的设计里城市、势力、军团的上限是绑在一起的：42 座城对应 42 个常规势力和 42 个常规军团（另有 4 个异族、
1 个贼，各自也有一个军团）。城市多了以后，常规势力和军团的空位会不够：剧本里放不下更多势力，游戏中途也没法再有
新势力独立、新军团组建。

`project.json` 的 `forces` 是常规势力（同时也是常规军团）的数量，最多 **249**，且不能超过城市数（另有 4 个异族、
1 个贼，各占一个势力和军团）；默认 42 和光荣一样。想让三者完全一致，就把它设成和 `cities` 相同（不超过 249）。改完运行：

```bat
python san11kit.py world
```

势力数不同，剧本和存档互不通用，要开新游戏（worldmod 读到不匹配的文件会在日志里报错）。
目前的限制（技术细节见 [M8_FORCES.md](../M8_FORCES.md)）：

* 国号只有 42 个空位：剧本里势力超过这个数，多出来的不设国号，游戏里用君主的名字称呼；编号 42 以后的势力也不能在游戏里改国号；
* 势力颜色只有 55 种，势力多了颜色会重复；
* 编号 42 以后的势力在选势力画面上没有介绍文字；
* 势力一览里「和各势力的关系」那几栏只对前 47 个势力有内容；编辑势力科技/国号的画面只能选前 47 个。

## 改部队数量上限

光荣的游戏里地图上最多同时有 **1000** 支部队（军队）。城市、势力多了以后打起仗来不够用：部队满了，谁也出不了兵。
`project.json` 的 `units` 是部队上限，1000~30000，默认 1000。改完运行：

```bat
python san11kit.py world
```

（只改部队数的话，也可以直接改 `worldmod.ini` 里对应那一节的 `units=`。）部队数改大以后，**以前的存档照样能读**；
反过来，部队多的存档拿到部队少的设置下读会出错（日志里报错）。技术细节见 [M9_UNITS.md](../M9_UNITS.md)。

## 城市从哪来

候选城市在三个文件里，都是普通文本：

| 文件 | 内容 |
|---|---|
| `data/new_cities.json` | 最重要的一批（罗马、长安以西的西域诸国、天竺……） |
| `data/cities_west.json` | 欧洲、西亚、北非约 300 座历史城市 |
| `data/cities_more.json` | 北欧、东欧、草原、印度、朝鲜、日本、东南亚约 300 座 |

`cities_west.json` 和 `cities_more.json` 每行一座城：

```json
["倫丁", "倫丁", "不列顛", 51.51, -0.1, 2]
```

依次是：游戏里显示的名字（最多 2 个字，繁体）、全名、地区、纬度、经度、重要程度（1 首府，2 大城，3 小城）。
加一行就多一个候选城，然后运行：

```bat
python san11kit.py world --reselect
```

`--reselect` 让工具重新挑城：按重要程度从高到低放，离已有城市不到 `spacing` 格（默认 14，光荣的中国是 13~21）就跳过。
所以想让某座城一定出现，就把它的重要程度设成 1。

## 地图编辑器

```bat
python san11kit.py editor
```

会在浏览器里打开编辑器：

- 「浏览」：拖动、滚轮缩放查看整个世界，颜色是地形（海、河、山、平原、道路……）
- 「地形」：用画笔改地形，比如给两座城之间挖一条路、把一片海填成陆地
- 「城市」：点选城市后拖动改位置，在右边改名字和地区，「上移/下移」调整它在城市表里的顺序（越靠前越先入选），「删除」去掉；双击空地加一座城
- 「保存」之后用「生成 / 部署…」重新生成游戏数据

编辑器改的是 `world_dir`（默认 `data/world`）里的地形和城市表。之后再运行 `san11kit.py world`（不加 `--fresh`、`--reselect`）会保留你的改动。

## 从头重新生成地形

```bat
python san11kit.py world --fresh
```

会丢掉编辑器里改过的地形和城市，按高程数据重新生成。想换世界的范围（比如只要中国加西域）需要改
`tools/make_world.py` 的参数，见 [TUTORIAL.md](../TUTORIAL.md) 第 5 节。

## 自动完成的事

每次 `world` 都会自动：

- **划领地**：每格地归走过去最近的城（山和河走起来代价高，所以边界沿山脊河流走），和光荣中国的区域自然衔接。
  放在中国区域里的新城从周围光荣城的区域里划地（关、港的区域和光荣城的内政用地不动）
- **修路**：沿相邻城市之间修主径，遇山修栈道、遇河修渡所；只能走海路的海岛城会单独列出来
- **相邻表**：哪些城相邻（每城最多 6 座相邻城），AI 和出征都靠它
- **城市模型**：新城在 3D 地图上的城池模型，和城下的地面找平
- **剧本转换**：光荣的 14 个剧本全部转成新的城市数（新城一开始都无主）
